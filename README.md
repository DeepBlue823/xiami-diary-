# 小咪的日记本

根目录 `index.html` 为公开阅读页，`edit.html` 为管理页。`api/` 提供接口，`lib/server.js` 共享连接、认证、验证、频率限制和并发写入逻辑。嵌套的 `xiami-diary/` 为历史副本，不用于当前部署。

## 开发和验证

使用 Node.js 22 或更新版本：

```sh
npm ci
npm test
```

测试使用内存数据库替身及 DOM 模拟，覆盖认证、参数验证、并发写入、页面安全渲染和异常恢复，不访问生产数据或外部生成服务。VM 模块的实验性提示属于测试环境提示。

## 配置与上线

在部署环境设置 `REDIS_URL`、`ADMIN_PASSWORD`。管理员密码没有默认值；缺少配置时登录会明确失败。语录功能沿用已有的可选服务配置，服务异常时页面使用本地备用语录。

推送主分支会触发部署，修改 API 后需等待新部署完成。部署前检查环境变量，并在部署后验证登录、创建/编辑日记、见面日期和评论。

本轮登录机制升级会使旧令牌失效，需要重新登录。旧令牌曾包含可解码的管理员密码，建议在部署设置中更换 `ADMIN_PASSWORD`。新令牌由随机数生成，有效期仍为七天，退出登录会撤销对应令牌。

日记与评论使用现有 JSON 存储格式，无需迁移。并发更新通过原子比较后写入保留其他请求的修改；冲突持续时返回 409，客户端可刷新后重试。小咪可以匿名评论；哥哥身份评论和删除需要登录。

`.vercelignore` 排除历史副本、测试、仓库备份和工作流，避免这些文件随网站公开。该规则不改变代码仓库本身的可见性。依赖锁文件纳入版本管理，`.env` 文件不应提交。

## 备份

每天北京时间 03:00 备份公开日记和见面日期，依赖工作流 secret `DIARY_URL`。本地另有备份校验与保留策略优化；工作流文件的上传需要 GitHub 令牌具备工作流写入权限。

当前自动备份不包含评论或登录会话。若需要完整灾备，应另外配置数据库快照；现有网站备份不能视为完整数据库备份。
